# Kontrak Eksekusi Fase

Setiap fase mencatat: ID kerja, tujuan, scope/out-of-scope, dokumen wajib, owner/reviewer, entry condition, aksi, risiko, evidence, exit condition, dan keputusan go/no-go pada `../16-log-eksekusi.md`.

`Done` berarti evidence tersedia dan reviewer sesuai otoritas sudah setuju. Jika keputusan/data/access belum ada, gunakan `Blocked`; jangan membuat mock production untuk melewati gate.
