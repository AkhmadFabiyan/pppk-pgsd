# Phase Delivery Map

Fase 01–36 adalah urutan eksekusi granular. Satu fase dapat memiliki banyak entry `EXE-*`, tetapi fase tidak selesai tanpa evidence dan gate. Phase 01–05 mengunci keputusan; 06–27 membangun; 28–33 membuktikan; 34–36 menjalankan event.

Gunakan `execution-contract.md` untuk setiap fase dan `acceptance-matrix.md` untuk memilih test yang harus lulus.
