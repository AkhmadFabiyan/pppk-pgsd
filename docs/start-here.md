# Mulai Di Sini

1. Baca `00-pedoman-eksekusi-berbasis-md.md` dan buat/temukan entry kerja pada `16-log-eksekusi.md`.
2. Baca `01-scope-dan-keputusan.md`; jangan menganggap keputusan `Menunggu panitia` sudah final.
3. Pilih domain dari `CATALOG.md`, lalu baca dokumen pemilik dan fase terkait.
4. Kerjakan hanya scope yang tercatat; gunakan fixture dummy sebelum T1–T4 production lulus.
5. Simpan bukti dan perbarui dokumentasi yang terdampak sebelum menutup entry.

Untuk implementasi baru, gunakan `phases/execution-contract.md`. Untuk tindakan panitia, gunakan `workflow/README.md` dan `09-sop-panitia.md`.

Untuk menjalankan build yang telah tersedia, baca `19-operasional-aplikasi.md` setelah langkah 1–3.
