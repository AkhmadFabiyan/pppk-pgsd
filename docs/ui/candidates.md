# UI — Section Kandidat `/#kandidat`

Memuat satu card per Candidate `published`: nomor urut, nama, kelas jika disetujui, photo/poster, tagline, dan tombol untuk membuka visi-misi inline. Urutan dari `ballot_number`; jangan gunakan angka nama file aset.

Card keyboard-accessible, image mempertahankan rasio sumber tanpa crop, dan pembeda kandidat tidak hanya warna. Detail dibuka tanpa perpindahan halaman. Empty state menjelaskan kandidat belum dipublikasikan; tidak mengungkap draft.
