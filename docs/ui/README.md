# UI Catalog

Setiap dokumen UI mendefinisikan tujuan layar, data yang boleh tampil, state, aksi, aksesibilitas, analytics yang dilarang, dan acceptance. Semua layar mengikuti kontrak **produk siap pakai**: tanpa demo/preview/data fiktif pada deployment production, memakai status event aktual dari server, responsif 320 px–desktop, dan motion fungsional yang menghormati reduced motion. Referensi utama: `../04-ui-ux-dan-visual.md` serta `../14-design-system.md`. Layar TV/proyektor hasil didefinisikan pada [live-results-display.md](live-results-display.md).
