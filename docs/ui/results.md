# UI — Section Hasil `/#hasil`

Mode bergantung `result_visibility`: hidden, turnout_only, atau full_live/final. Section hasil menampilkan count, percent, total valid, turnout, revision/timestamp, dan fallback stale state bila diizinkan; tidak pernah list pemilih atau angka fiktif.

Bar grafis mempunyai label angka dan table alternatif. Realtime failure menampilkan waktu pembaruan terakhir dan polling fallback, bukan angka buatan.
