# UI — Receipt `/bukti/[receiptCode]`

Menampilkan konfirmasi penerimaan, kode receipt, waktu, kanal bantuan, dan link public safe. Ia tidak menampilkan kandidat terpilih, NIM, device/IP, atau status voter lain.

Route bersifat `noindex`, cache-safe, dan defensif pada code invalid/expired. Copy memberi tahu bahwa receipt bukan sarana mengubah suara.
