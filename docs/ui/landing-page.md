# UI — Landing Page `/`

Ini adalah satu-satunya halaman visitor. Ia menampilkan nama event, status periode, CTA kandidat/vote, kandidat, detail visi-misi inline, turnout/hasil sesuai visibility, panduan, bantuan, dan privacy notice. Tidak menampilkan NIM, admin control, raw vote, atau data draft.

Hero hutan adalah scene interaktif: layer horizon bergerak mengikuti scroll, cahaya mengikuti pointer desktop, daun/ticker bergerak sebagai dekorasi, dan CTA memiliki shimmer singkat. Kandidat memakai reveal saat masuk viewport serta spotlight/tilt pointer ringan. Semua informasi, CTA, dan anchor navigation tetap dapat dicapai tanpa animation maupun pointer. State: draft/scheduled/open/closed/maintenance. Saat hasil tidak boleh publik, ganti perolehan calon dengan copy kebijakan yang jelas.
