# UI — Landing Page `/`

Ini adalah satu-satunya halaman visitor. Ia menampilkan nama event, status periode, CTA kandidat/vote, kandidat, detail visi-misi inline, turnout/hasil sesuai visibility, panduan, bantuan, dan privacy notice. Tidak menampilkan NIM, admin control, raw vote, atau data draft.

Hero hutan adalah satu scene interaktif yang ringkas: dua layer horizon bergerak mengikuti scroll, cahaya mengikuti pointer desktop, maksimal tujuh daun bergerak sebagai aksen, CTA memiliki shimmer singkat, dan pesan pendukung memakai typewriter yang tidak memblokir CTA. Copy utama memakai kata kerja langsung: `Lihat semua calon`, `Masuk ke bilik suara`, dan `Lihat cara memilih`. Tidak ada ticker, noise/grain, orbit, confetti, atau efek dekoratif kedua. Section informasi memakai tile yang masuk bertahap, kandidat memakai reveal serta glow/tilt pointer ringan, langkah voting memiliki progress line, hasil memakai count/bar dari data nyata, dan bantuan memakai affordance hover/tap. Semua informasi, CTA, dan anchor navigation tetap dapat dicapai tanpa animation maupun pointer. State: draft/scheduled/open/closed/maintenance. Saat hasil tidak boleh publik, ganti perolehan calon dengan copy kebijakan yang jelas.
