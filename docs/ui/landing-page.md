# UI — Landing Page `/`

Ini adalah satu-satunya halaman visitor. Ia menampilkan nama event, status periode, CTA kandidat/vote, kandidat, detail visi-misi inline, turnout/hasil sesuai visibility, panduan, bantuan, dan privacy notice. Tidak menampilkan NIM, admin control, raw vote, atau data draft.

Hero hutan adalah satu scene interaktif yang ringkas: dua layer horizon bergerak mengikuti scroll, cahaya mengikuti pointer desktop, maksimal tujuh daun bergerak sebagai aksen, dan CTA memiliki shimmer singkat. Tidak ada ticker, noise/grain, orbit, confetti, atau efek dekoratif kedua. Kandidat memakai reveal saat masuk viewport serta glow/tilt pointer ringan. Semua informasi, CTA, dan anchor navigation tetap dapat dicapai tanpa animation maupun pointer. State: draft/scheduled/open/closed/maintenance. Saat hasil tidak boleh publik, ganti perolehan calon dengan copy kebijakan yang jelas.
