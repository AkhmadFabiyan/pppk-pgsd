# UI — Landing Page `/`

Ini adalah satu-satunya halaman visitor. Ia menampilkan nama event, status periode, CTA kandidat/vote, galeri kandidat, turnout/hasil sesuai visibility, panduan, bantuan, dan privacy notice. Tidak menampilkan NIM, admin control, raw vote, data draft, visi, atau misi kandidat.

Hero hutan adalah satu scene interaktif yang ringkas: GSAP hanya menjalankan satu entrance setelah konten tersedia untuk horizon, label, dua baris judul, detail, dan panel event. Cahaya mengikuti pointer desktop, maksimal tujuh daun bergerak sebagai aksen, CTA memiliki shimmer singkat, dan pesan pendukung memakai typewriter yang tidak memblokir CTA. Tidak ada scroll hijacking, ScrollTrigger global, ticker, noise/grain, confetti, atau efek dekoratif kedua. Section informasi memakai tile Motion yang masuk sekali, kandidat memakai reveal/hover ringan, langkah voting memiliki progress line, hasil memakai count/bar dari data nyata, dan bantuan memakai affordance hover/tap. Semua informasi, CTA, dan anchor navigation tetap dapat dicapai tanpa animation maupun pointer. State: draft/scheduled/open/closed/maintenance. Saat hasil tidak boleh publik, ganti perolehan calon dengan copy kebijakan yang jelas. Detail batas teknologi ada di `../21-redesign-civic-forest.md`.
