# Glosarium Operasional

| Istilah | Arti |
| --- | --- |
| Event | Satu periode pemilihan dengan konfigurasi, calon, eligible voter, dan hasil sendiri. |
| Candidate | Satu calon individu yang dipilih pada ballot. |
| Voter | Record internal pemilik NIM pada master. |
| Eligible | Voter yang berhak memilih pada event tertentu. |
| Vote | Satu pilihan final, immutable, dan terkait event/candidate/voter yang valid. |
| Receipt | Kode acak untuk membuktikan penerimaan suara tanpa membuka kandidat atau NIM. |
| Revision | Nomor versi agregat hasil untuk mendeteksi update realtime yang terlewat. |
| Void | Pembatalan resmi yang ber-audit; bukan edit vote. |
| Preview import | Validasi spreadsheet sebelum data committed. |
| Freeze | Masa ketika perubahan production dibatasi sebelum/dalam event. |
