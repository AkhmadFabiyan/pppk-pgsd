# Accessibility dan Motion

Semua route dapat dipakai keyboard, screen reader, zoom, dan layar 320 px. Form memiliki label, error yang diumumkan, focus return dari dialog, dan state pilihan tidak bergantung pada warna.

`prefers-reduced-motion` menghentikan parallax, daun, ticker, pulse, pointer spotlight, dan reveal panjang. Pada pointer touch, efek tilt/spotlight tidak menjadi prasyarat interaksi. Animation callback tidak pernah menentukan sukses/gagal vote.
