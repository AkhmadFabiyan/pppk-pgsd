# Performance Budget

Prioritaskan route ballot dan verify/submit. Tetapkan budget bundle, LCP, INP, p95 verify/submit, error rate, dan concurrency berdasarkan proyeksi peserta sebelum UAT. Poster/image memakai ukuran responsif dan lazy loading.

Motion adalah progressive enhancement: tidak memblokir input atau mengubah state bisnis. Pada `prefers-reduced-motion`, motion non-fungsional langsung disederhanakan/dimatikan. GSAP adalah exception terbatas untuk entrance hero beranda dan tidak direferensikan oleh route vote, admin, maupun live; tidak ada 3D/canvas pada aplikasi ini.
