# Register Keputusan

| ID | Keputusan | Status | Owner | Bukti sebelum close |
| --- | --- | --- | --- | --- |
| DEC-01 | Semua master atau peserta bertanda hadir yang eligible. | Menunggu panitia | Admin event | Count approved + import preview. |
| DEC-02 | Posisi pemilihan, sembilan calon, nomor urut, dan hak pilih calon. | Menunggu panitia | Panitia | Review dua admin. |
| DEC-03 | Buka/tutup WIB, masa sengketa, dan mode hasil live. | Menunggu panitia | Admin event | Config snapshot. |
| DEC-04 | Faktor verifikasi kedua/risiko NIM-only. | Menunggu panitia | Pemilik data | Threat-model sign-off. |
| DEC-05 | Retensi, owner data, backup, dan kanal insiden. | Menunggu panitia | Panitia | SOP dan policy. |
| DEC-06 | Domain canonical, hosting, DB, auth, storage, realtime. | Menunggu teknis | Admin + teknis | ADR T4. |

Hanya panitia/pemilik keputusan dapat mengubah `Menunggu` menjadi `Disetujui`; sertakan tanggal, alasan, dan entry log.
