# Workflow — Setup Event

1. Buat event `draft`; tetapkan title, slug, timezone, visibility, dan pemilik.
2. Isi keputusan DEC-01–DEC-05 dan konfigurasi anti-abuse.
3. Tambah calon dan eligible melalui workflow masing-masing.
4. Admin kedua review preview/config; simpan snapshot.
5. Jadwalkan `scheduled`; jangan open tanpa checklist pembukaan.

Evidence: audit create/config, sign-off, dan config checksum.
