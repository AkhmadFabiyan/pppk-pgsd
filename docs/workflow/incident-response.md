# Workflow — Incident Response

Triage severity, stabilkan integritas (pause/close bila perlu), preserve evidence, catat timeline, eskalasi owner, komunikasikan fakta publik, pulihkan, rekonsiliasi, lalu postmortem. Jangan menghapus log/vote untuk mempercepat pemulihan.

SEV-1/SEV-2 membutuhkan admin penanggung jawab; copy publik tidak memuat spekulasi atau PII.
