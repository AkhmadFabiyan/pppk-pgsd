# Workflow Catalog

Workflow menjelaskan tindakan manusia/admin. Ia menggunakan dua role aplikasi saja (`visitor`, `admin`), tetapi dapat menetapkan pengaju dan penyetuju sebagai dua akun admin berbeda.

Sebelum menjalankan workflow, buat/check entry `EXE-*`; sesudahnya simpan audit/bukti tanpa PII di log umum.
