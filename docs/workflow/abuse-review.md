# Workflow — Review Anomali

Monitoring mendeteksi sinyal agregat: rate-limit spike, failed verify, duplicate submit, error, atau lonjakan device/network sesuai kebijakan. Sinyal bukan vonis; jangan memblokir hak pilih hanya dari IP/fingerprint.

Admin review mencatat waktu/impact/evidence, menerapkan mitigasi yang disetujui, dan eskalasi SEV sesuai SOP.
