# Workflow — Publikasi Hasil

Saat event open, ikuti `result_visibility`. Saat closed, admin review merekonsiliasi total vote, snapshot, export checksum, dan audit sebelum hasil final disahkan. Humas memakai template tanpa PII.

Perubahan visibility/config selama open memerlukan keputusan ber-audit; jangan menyebarkan dashboard internal sebagai hasil resmi.
