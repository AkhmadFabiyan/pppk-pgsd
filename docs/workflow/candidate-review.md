# Workflow — Review Kandidat

Admin pertama memasukkan draft dari inventaris, menautkan NIM melalui mapping restricted, mengisi nomor urut dan materi publik. Admin kedua mencocokkan poster/master/izin, memeriksa preview mobile, lalu approve/reject dengan alasan.

Nama singkat pada poster dikonfirmasi panitia/calon. Candidate hanya menjadi `published` setelah semua checklist `11-setup-calon-individu.md` lulus.
