# Workflow — Export dan Arsip

Admin meminta export dengan purpose/scope, approval bila restricted, dan waktu expiry. Sistem menghasilkan file scoped, checksum, audit create/download, dan storage approved. Export tidak dikirim ke grup/chat publik.

Setelah sengketa/retensi, owner menghapus atau menganonimkan sesuai DEC-05 dan mencatat evidence.
